### U3 — Fix SHAPE_CIRCLE renders ellipse inscribed in bounds

**Goal:** `SHAPE_CIRCLE` renders an ellipse inscribed in its bounding box, not a circle constrained to the shorter side.

**Files:**
- Modify: `lib/features/match/session/overlay_renderer.dart`
- Modify: `test/features/match/session/overlay_renderer_test.dart`

**Approach:** Replace `BoxShape.circle` with a `Container` using `BoxDecoration(shape: BoxShape.rectangle, borderRadius: BorderRadius.circular(largeValue))` — or use `CustomPaint` with `canvas.drawOval(rect, paint)` where `rect` is the full bounds. The `CustomPaint` approach is more correct for non-square bounds.

**Test scenarios:**
- Square bounds: renders a circle (width == height)
- Non-square bounds (e.g. 100×50): fills the full rect as an oval, not a circle clipped to 50×50

**Verification:** New test passes; existing tests pass.
