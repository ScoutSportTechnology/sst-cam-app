# Historical version reset

The old `v0.1.0` tag and Release were created by a retired push-to-main
workflow before the alpha/beta/rc maturity ladder. The one-time reset removed
that untested tag and let `development` mint the first `v0.1.0-alpha.N`.

This operation is complete. Do not delete or move tags as part of routine
releases. Current release commands and required checks are documented in
`AGENTS.md` and [rulesets.md](rulesets.md).
