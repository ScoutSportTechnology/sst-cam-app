# ScoutCamera App

**Mobile companion app for the ScoutCamera — an open-source sports camera with AI-powered tracking.**

This repository contains the Flutter app designed to connect to and control the ScoutCamera.

## Status
This project is in a **very early stage**.  
- Initial experiments with **Bluetooth connection and discovery** have been started.  
- The app is intended to provide:  
  - Camera control (start/stop recording, streaming).  
  - Preview and download of archived footage.  
  - Future extensions like overlays and real-time controls.  

Right now the focus is on **testing Bluetooth communication** as the first integration step with the camera firmware.

## Development Notes
- Built with **Flutter** for Android and iOS support.  
- Code is evolving as I learn and test features.  
- Expect incomplete features, placeholders, and experimental commits.  

## Roadmap
1. Reliable Bluetooth discovery and pairing.  
2. Basic control commands (record/stop/preview).  
3. Downloading archived footage.  
4. Integration with new firmware features (zoom, AI tracking, scoreboard overlay).  

## Contributing
This is a personal side project at the moment, but suggestions, bug reports, and pull requests are always welcome. Feedback on architecture and Flutter best practices is especially appreciated.
